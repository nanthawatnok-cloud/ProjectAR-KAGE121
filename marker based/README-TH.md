# วิธีเพิ่มไฟล์ AR (สำหรับผู้เริ่มต้น)

ไม่ต้องแก้ `index.html` และไม่ต้องคัดลอก `<a-marker>` เพิ่มเอง

1. นำไฟล์สื่อกับไฟล์ marker ใส่ในโฟลเดอร์ `assets`
2. ตั้งเลขท้ายชื่อให้ตรงกัน เช่น `asset4.png` คู่กับ `marker4.patt`
3. ดับเบิลคลิก `START_AR.cmd` เพื่อสร้างรายการไฟล์และเปิดเว็บทดสอบ

ชนิดไฟล์สื่อที่ใช้ได้: `.glb`, `.gltf`, `.zip`, `.png`, `.jpg`, `.jpeg`, `.gif`, `.mp4`

ตัวอย่างชื่อไฟล์:

```text
assets/
  asset1.glb     marker1.patt
  asset2.png     marker2.patt
  asset3.mp4     marker3.patt
```

วิธีควบคุมสื่อเมื่อส่องพบ marker:

- แตะ/คลิกที่สื่อแล้วลาก เพื่อขยับ
- ใช้ 2 นิ้วกางหรือหุบ เพื่อย่อ/ขยาย
- ใช้ 2 นิ้วบิด เพื่อหมุน
- บนคอมพิวเตอร์ ใช้ล้อเมาส์เพื่อย่อ/ขยาย

ห้ามเปิด `index.html` โดยดับเบิลคลิกโดยตรง เพราะกล้องเว็บต้องทำงานผ่านเว็บเซิร์ฟเวอร์ ให้เปิดผ่าน `START_AR.cmd` เสมอ ในการใช้งานบนโทรศัพท์จริงควรอัปโหลดขึ้น HTTPS (เช่น GitHub Pages)

ถ้าอัปโหลดไฟล์ขึ้น GitHub โปรเจกต์นี้มี GitHub Actions ที่สร้าง `manifest.json` ให้อัตโนมัติหลังอัปโหลด จึงไม่ต้องเปิด `START_AR.cmd` บน GitHub
